## 🚀 À propos de moi

Développeur spécialisé dans la conception de solutions **backend** et **full stack**.

Je m’intéresse particulièrement à :

* la conception d’architectures robustes ;
* le développement d’API REST sécurisées ;
* la qualité et la maintenabilité du code ;
* la modélisation des données ;
* l’optimisation des performances ;
* l’intégration continue et le déploiement ;
* la résolution de problématiques métier complexes.

J’accorde une grande importance aux bonnes pratiques de développement, à la sécurité et à la création d’applications réellement utiles aux utilisateurs.
